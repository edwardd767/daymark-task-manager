# Daymark Task Manager

A React + Vite task manager with Supabase authentication and database storage.

## Connect Supabase

Copy `.env.example` to a new file named `.env` and add your Supabase Project URL and publishable/anon key. Never put the service-role key in this app.

## Run locally

```bash
npm install
npm run dev
```

## Build for hosting

```bash
npm run build
```

Deploy the generated `dist` directory, or connect this repository directly to Netlify.
